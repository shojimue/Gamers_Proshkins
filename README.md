## 📖 О проекте

**Gamers Proshkins** — это современная веб-платформа для быстрой и безопасной покупки лицензионных ключей для компьютерных игр. Мы делаем процесс пополнения игровой библиотеки простым, моментальным и приятным, предлагая конкурентоспособные цены и полную защиту каждой транзакции.

Проект создан для геймеров, которые ценят свое время и деньги и хотят получать игры сразу после оплаты, без ожидания и лишних рисков.

### ✨ Основные возможности

- **Каталог товаров** с фильтрацией по платформам (Steam, Epic Games, Origin, Uplay) и игровым жанрам.
- **Мгновенная выдача ключей** — активационный код появляется в личном кабинете сразу после успешного платежа.
- **Личный кабинет** с детальной историей всех покупок и статусом каждого заказа.
- **Гибкая система скидок** и промокодов для постоянных покупателей.
- **Отзывы и рейтинг** — сообщество геймеров помогает выбирать лучшие игры.

## ⚙️ Как создавалось приложение

Мы строили **Gamers Proshkins** с упором на три столпа: **производительность**, **безопасность** и **удобство**. Именно это определило выбор архитектуры и технологий.

### 🧱 Архитектура и стек технологий

Проект представляет собой **Single Page Application (SPA)**, что гарантирует мгновенный отклик интерфейса и плавную работу без перезагрузок страниц.

| Компонент       | Технологии                                                                 | Назначение                                                                 |
|-----------------|----------------------------------------------------------------------------|----------------------------------------------------------------------------|
| **Бэкенд**      | Python, Django REST Framework, PostgreSQL, Redis                           | Создание надежного API, управление базой данных товаров и пользователей.   |
| **Фронтенд**    | React.js, Redux Toolkit, Material-UI                                       | Разработка интерактивного и адаптивного пользовательского интерфейса.      |
| **Платежи**     | ЮKassa API (или Stripe), Django REST Framework                             | Интеграция с защищенными платежными шлюзами для приема оплаты.             |
| **Безопасность**| JWT-аутентификация, шифрование ключей (AES-256), HTTPS                     | Защита данных пользователей и цифровых товаров.                            |
