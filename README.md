# Gamers_Proshkins

**Интернет-магазин цифровых товаров и активации ключей игр**

## О проекте

**GamersProshkins** — это современная веб-платформа для быстрой и безопасной покупки лицензионных ключей для компьютерных игр. Мы делаем процесс пополнения игровой библиотеки простым, моментальным и приятным, предлагая конкурентоспособные цены и полную защиту каждой транзакции.

Проект создан для геймеров, которые ценят свое время и деньги и хотят получать игры сразу после оплаты, без ожидания и лишних рисков.

## Основные возможности

- **Каталог товаров** с фильтрацией по платформам и игровым жанрам.
- **Мгновенная выдача ключей** — активационный код появляется в личном кабинете сразу после платежа.
- **Личный кабинет** с детальной историей всех покупок и статусом каждого заказа.
- **Гибкая система скидок** и промокодов для постоянных покупателей.
- **Отзывы и рейтинг** — сообщество геймеров помогает выбирать лучшие игры.

## Как создавалось приложение

Мы строили **GamersProshkins** с упором на три столпа: **производительность**, **безопасность** и **удобство**. Именно это определило выбор архитектуры и технологий.

| Компонент | Технологии | Назначение |
|---|---|---|
| **Бэкенд** | Python, Django, PostgreSQL | Создание надежного API, управление базой данных товаров и пользователей. |
| **Фронтенд** | React.js, Material-UI | Разработка интерактивного и адаптивного пользовательского интерфейса. |
| **Платежи** | ЮKassa API, Django, | Интеграция с защищенными платежными шлюзами для приема оплаты. |
| **Безопасность** | JWT-аутентификация, HTTPS | Защита данных пользователей и цифровых товаров. |

## **Безопасное хранение ключей:**
    Каждый игровой ключ хранится в зашифрованном виде. Процесс активации выглядит так:

    ```mermaid
    graph TD
        A[Пользователь оплачивает заказ] --> B{Платеж успешен?};
        B -- Да --> C[Резервирование и расшифровка ключа];
        C --> D[Ключ отображается в ЛК и отправляется на email];
        B -- Нет --> E[Заказ отклонен, ключ не выдан];
