## 📖 О проекте

**GamersProshkins** — это высоконагруженный интернет-магазин цифровых товаров, разработанный в рамках курсового проекта по дисциплине МИАПО. Система автоматизирует процесс покупки, генерации и выдачи лицензионных ключей, предоставляя пользователям мгновенный доступ к приобретенным продуктам.

### 🎯 Цель работы

Разработать полнофункциональное веб-приложение, обеспечивающее:

1. Каталогизацию цифровых товаров с категоризацией
2. Мгновенную генерацию уникальных активационных ключей
3. Безопасное хранение и выдачу ключей[^1]
4. Аналитику продаж и пользовательского поведения
5. Масштабируемость до 10 000 одновременных пользователей

[^1]: Ключи хранятся в зашифрованном виде и удаляются после первой выдачи пользователю.

## ✨ Ключевые возможности

Система предоставляет следующий функционал:

### Для пользователей

- 🔐 **Регистрация и авторизация** с подтверждением email
- 🛒 **Корзина** с возможностью управления количеством товаров
- 💳 **Оплата** через тестовый платежный шлюз
- 📧 **Автоматическая выдача ключа** на email после оплаты
- 💰 **Система кешбэка** — 5% от каждой покупки
- 📊 **Личный кабинет** с историей заказов
- ⭐ **Система отзывов** к товарам

### Для администраторов

- 📦 **Управление товарами** (CRUD операции)
- 📈 **Дашборд аналитики**:
  - Количество продаж за период
  - Топ популярных товаров
  - Воронка конверсии
  - Средний чек
- 👥 **Управление пользователями** (блокировка, выдача прав)
- 🎫 **Генерация ключей** пачками (до 1000 шт. за раз)

### Технические характеристики

| Параметр | Значение |
|:---------|:---------|
| Максимальная нагрузка | 10 000 RPS[^2] |
| Среднее время ответа API | < 50 мс |
| Время генерации ключа | < 1 секунда |
| Доступность (SLA) | 99.9% |

[^2]: RPS — Requests Per Second (запросов в секунду)

## 🛠 Технологии

### Backend

| Компонент | Технология | Версия | Назначение |
|:----------|:-----------|:-------|:-----------|
| Язык программирования | Python | 3.10+ | Основной язык разработки |
| Веб-фреймворк | Django | 4.2 | Бизнес-логика и ORM |
| REST API | Django REST Framework | 3.14 | Создание API эндпоинтов |
| База данных | PostgreSQL | 15 | Основное хранилище данных |
| Кеширование | Redis | 7.0 | Кеш, сессии, очереди |
| Асинхронные задачи | Celery | 5.3 | Отправка писем, генерация ключей |
| Платежный шлюз | YooKassa (песочница) | — | Тестирование оплаты |
| Аутентификация | JWT + Django Sessions | — | Авторизация пользователей |

### Frontend

| Компонент | Технология | Назначение |
|:----------|:-----------|:-----------|
| Вёрстка | HTML5 / CSS3 | Структура и стилизация |
| CSS Фреймворк | Bootstrap 5 | Адаптивный дизайн |
| Интерактивность | JavaScript (ES6) | Динамический контент |
| Графики | Chart.js | Визуализация аналитики |
| AJAX запросы | Fetch API / Axios | Асинхронное взаимодействие |

### DevOps

| Инструмент | Назначение |
|:-----------|:-----------|
| Docker / Docker Compose | Контейнеризация и оркестрация |
| Nginx | Обратный прокси и раздача статики |
| Gunicorn | WSGI сервер для продакшна |
| GitHub Actions | CI/CD (планируется) |
